Frequently Asked Questions

What is the purpose of this page?

This page demonstrates a simple FAQ accordion with five collapsible sections.

How does the accordion work?

Clicking a heading expands its content and automatically collapses any other open sections.

Can I customize the style?

Yes, modify the CSS inside the <style> tag to change colors, fonts, and spacing.

Is JavaScript required?

JavaScript is used to ensure only one section is open at a time. Without it, all sections can be opened independently.

Where can I see the source?

The entire source code is contained in this single HTML file – no external files or assets.

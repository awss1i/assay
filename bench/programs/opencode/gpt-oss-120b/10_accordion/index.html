Frequently Asked Questions

What is this page about?

This page demonstrates a simple FAQ with collapsible sections built purely with HTML, CSS, and JavaScript.

How does the collapsible behavior work?

When a heading is clicked, JavaScript toggles its active state and expands its answer while collapsing any other open answer.

Can I add more sections?

Yes – just copy one of the .item blocks and modify the text of the question and answer.

Is any external library required?

No. All styles and scripts are inline, so the page works offline without any build step.

Will this work in all browsers?

It uses only standard HTML5, CSS3, and vanilla JavaScript, so it works in any modern browser.

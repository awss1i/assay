## <a id="the-skill"></a>Skill

Skill работает во всех пятнадцати поддерживаемых harness.
[`skills/checking-a-page/SKILL.md`](skills/checking-a-page/SKILL.md) велит агенту, закончив
страницу, выполнить эту команду.

```bash
assay <the page> --one-line
```

Затем агент должен завершить ответ выводом этой команды, слово в слово.

```
assay: checked todo/todo.html, 8 checks, nothing flagged.
```

Когда что-то не в порядке, вывод выглядит иначе.

```
assay: checked notes/index.html, 12 checks, 4 flagged:
  - press Clear all: the page threw an error and stopped running, Cannot set properties of null (setting 'innerHTML')
  - press Clear all twice (same finding as press Clear all)
  - press Add, then Clear all (same finding as press Clear all)
  - press Clear all, then Add (same finding as press Clear all)
```

Эти четыре строки описывают один баг. Повторы ссылаются на первое замечание (finding), а не
повторяют его сообщение. Агент копирует вывод assay, а не пересказывает его, поэтому числа и
формулировки остаются точными. Если используется только skill, агент сам решает, когда запускать
проверку (check).

## <a id="the-plugin"></a>Плагин

Плагин (plugin) добавляет хук (hook) `Stop`, который запускает проверку в конце каждого хода
(turn), изменившего страницу. В Claude Code плагин устанавливает skill и хук вместе. DeepSeek
Harness использует только хук, через свой мост к Claude Code.

- **Какие страницы проверяются.** Изменение любого веб-файла отмечает для проверки страницу в той
  же папке, так что правка `app.js` тоже считается. В каждой папке проверяется последний
  изменённый файл `.html`, а при равном времени изменения предпочтение отдаётся `index.html`.
- **Насколько глубоко он смотрит.** Хук заглядывает не глубже чем на четыре уровня папок,
  пропускает `node_modules` и `.git`, учитывает только файлы, изменённые после его прошлого
  запуска, и проверяет не больше трёх страниц за ход.
- **Он всегда отчитывается**, когда проверяет страницу, так что чистый результат нельзя принять
  за то, что assay не запускался. Если за ход не изменилась ни одна страница, хук ничего не
  сообщает.
- **Он не даёт ходу завершиться**, чтобы вы увидели результат, и никогда не делает этого два раза
  подряд. Для этого хук проверяет флаг `stop_hook_active` у harness и записывает отметку времени
  (во временную папку harness, иначе в `.git/`, иначе в файл `.assay-last-run`). Если записать
  отметку времени не удаётся, хук сообщает результат, не задерживая ход.

## <a id="reporting-not-fixing"></a>Отчёт без исправлений

Агент показывает, что нашёл assay, и не меняет из-за этого код, если вы не попросите. assay не
знает, для чего нужна страница, поэтому замечание указывает место, куда стоит посмотреть, а не
подтверждённый баг. Элемент управления (control) может совершенно правильно ничего не делать в
том состоянии, в котором его нажали, а значение может быть ограничено намеренно. Попросите агента
что-то исправить, и он исправит.
